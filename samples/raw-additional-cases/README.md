# Additional Raw Mapping Cases

These are raw fact-find style YAML cases intended to extend coverage beyond `samples/raw-halifax-cases`.

They are deliberately lender-neutral raw inputs so the existing Halifax, Barclays, Skipton, Virgin Money, and HSBC mapping scripts can be pointed at this folder.

## Coverage

| Case | Scenario |
| --- | --- |
| `additional-raw-case-11-ftb-joint-employed-contractor-umbrella.yaml` | First-time buyer, joint applicants, employed plus umbrella contractor. |
| `additional-raw-case-12-remortgage-paydown-no-additional.yaml` | Remortgage with paydown and no additional borrowing. |
| `additional-raw-case-13-shared-ownership-remortgage-staircasing.yaml` | Shared ownership remortgage with additional share/staircasing. |
| `additional-raw-case-14-shared-equity-remortgage-partial-redemption.yaml` | Help to Buy/shared equity remortgage with partial redemption and part-and-part. |
| `additional-raw-case-15-further-advance-joint-pension-employed.yaml` | Further advance with retired pension applicant plus employed applicant. |
| `additional-raw-case-16-purchase-not-working-benefits-maintenance.yaml` | Benefits-led and maintenance income with childcare. |
| `additional-raw-case-17-high-dependants-large-family.yaml` | Joint large-family case with more than nine dependants. |
| `additional-raw-case-18-short-current-employment.yaml` | Employed applicant with under-six-month current employment. |
| `additional-raw-case-19-short-self-employed-trading.yaml` | Sole trader with under-24-month trading history. |
| `additional-raw-case-20-contractor-my-company-salary-dividends.yaml` | Contractor via own company with salary, dividends, and profit. |
| `additional-raw-case-21-contractor-weekly-rate.yaml` | Contractor using weekly-rate income. |
| `additional-raw-case-22-limited-company-loss-previous-year.yaml` | Limited company director with previous-year loss. |
| `additional-raw-case-23-llp-salary-plus-profit-investment-income.yaml` | LLP with salary/profit, investment income, and part-and-part. |
| `additional-raw-case-24-wales-commonhold-heavy-outgoings.yaml` | Wales/commonhold case with household expenditure. |
| `additional-raw-case-25-northern-ireland-remortgage-employed.yaml` | Northern Ireland remortgage with student loan. |
| `additional-raw-case-26-other-properties-mixed-btl-residential.yaml` | Mixed BTL, residential mortgaged, and mortgage-free other properties. |
| `additional-raw-case-27-interest-only-sale-of-property-repayment-vehicle.yaml` | Interest-only purchase using sale of property repayment vehicle. |
| `additional-raw-case-28-joint-retired-and-not-working-benefits.yaml` | Joint retired plus not-working benefits income remortgage. |
| `additional-raw-case-29-foreign-national-ilr-joint-case.yaml` | Joint FTB with foreign national ILR and lease commitment. |
