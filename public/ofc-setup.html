Open Filled Calculator setup

Install Google Chrome and the Open Filled Calculator companion on this computer once. You do not need a Chrome extension, Node.js, npm, or a lender login.

  1. Download and install the companion for your operating system. If there is no download button here, ask the website administrator for the installer.
  2. Return to a case and click Open filled calculator beside a lender.
  3. Allow your browser to open the companion. The first time, approve your website's address in the companion.
  4. Chrome opens the lender calculator with the mapped fields filled. Edit the fields there. The companion stops before requesting the affordability result.

The companion checks for updates automatically. If lender code changes, it downloads a newer release and installs it after open Chrome sessions close. Then click Open filled calculator again. If an older 0.1.x companion is installed, install the current version here once to enable automatic updates.
